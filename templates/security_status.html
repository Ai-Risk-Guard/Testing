AUREX Vulnerability Lab

This environment is designed to demonstrate application security testing using a fictional banking application.

Intentionally Vulnerable Authentication

The initial version constructs its login SQL query by combining SQL syntax with user-supplied input. This is an intentional SQL injection vulnerability.

Hardcoded Demonstration Secret

The application configuration contains a synthetic hardcoded value intended for security-scanner evaluation. It is not a real credential or a functioning API key.

Fictional Data

All account names, balances, account numbers, and transactions are created for this local demonstration. No real banking service is connected.

Testing Objective

Identify the vulnerable code, apply an appropriate fix, and repeat the same regression tests to verify that the original behavior is no longer possible.
